Privacy Policy

Covers the internal automation tool that publishes this channel's own videos to its own TikTok account.

Effective 2026-09-09 · Applies to app "莎莎聊财经自动发布"

01 Who this covers

This tool has exactly one user: the operator of Finance with Shasha (莎莎聊财经). It is not a public app, has no sign-up flow, and does not collect information from anyone other than that one operator. There is no audience-facing data collection to describe here — the content it publishes is the channel's own finished video, not anything gathered from viewers.

02 What the tool touches

DataWhy
TikTok access & refresh tokensIssued by TikTok's own OAuth login when the operator authorizes the tool, so it can call the Content Posting API on the operator's behalf.
Video files & captionsAlready-produced episodes and their metadata (title, description, tags), read from local storage in order to upload them.

Nothing else is read, requested, or logged. The tool has no database of viewers, followers, or comments.

03 Where it lives

Tokens and video files stay on the operator's own machine. Nothing is sent to a third-party server, sold, or shared with any other person or company — the only network calls this tool makes are directly to TikTok's own API, to publish the operator's own videos to the operator's own account.

04 Retention & revocation

Access tokens are kept locally until either the tool is decommissioned or the operator revokes access. Revoking is done the same way as any third-party app: from within TikTok, under Settings and privacy → Security and permissions → Manage apps.

Revoking access there immediately stops the tool from publishing — no separate request to us is needed.

05 Changes

If what the tool touches ever changes, this page will change with it. The date at the top always reflects the current version.
