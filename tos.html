01 What this is

This tool is a first-party, internal automation script built and operated by the team behind Finance with Shasha (莎莎聊财经). Its only function is to take videos this channel has already produced — narrated daily market-news and analysis — and publish them to the channel's own TikTok account, @financewithshasha, using TikTok's Content Posting API.

It is not a public product. Nobody outside the channel's own operator can use it, connect an account to it, or request that it publish on their behalf.

The tool authenticates as the channel operator and publishes only to accounts the operator has personally authorized through TikTok's own login flow. It never posts to, reads from, or acts on any account other than the one it was explicitly connected to.
